    About this model

    FashionCNN is a custom Convolutional Neural Network trained with PyTorch on the Fashion-MNIST dataset. Each input image is resized to 28×28 grayscale pixels, normalized to [0, 1], and evaluated directly in your browser using ONNX Runtime Web with no server upload.

    Note: This model was trained on centered 28×28 Fashion-MNIST clothing silhouettes and achieves approximately 89% test accuracy on that dataset. Predictions on ordinary photographs of clothing may be unreliable.
